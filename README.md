## Introduction

This is MCUXpresso SDK fork of FatFs (filesystem created by ChaN).
Official documentation is available at [http://elm-chan.org/fsw/ff/](http://elm-chan.org/fsw/ff/)

MCUXpresso version is extending original content by following hardware specific porting layers:

 - mmc_disk
 - nand_disk
 - ram_disk
 - sd_disk
 - sdspi_disk
 - usb_disk

MCUXpresso SDK repository: [https://github.com/nxp-mcuxpresso/fatfs](https://github.com/nxp-mcuxpresso/fatfs)
